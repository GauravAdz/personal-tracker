## Decisions / blockers
- Architecture is governed by `docs/ARCHITECTURE.md`.
- V1 deliberately excludes cloud sync and AI.
- T01 uses Node 24 (verified on 24.18.1), exact direct dependency versions and npm lockfile. TypeScript 6.0.3 stays within the installed typescript-eslint supported range (<6.1); Node 24 satisfies the installed Vite/Vitest/ESLint toolchain.
- React Router hash URLs support static hosting without server rewrites; relative Vite asset paths support deployment under a subdirectory.
- T01 introduced no database, domain models, validation schemas, service worker, installation metadata or feature behavior ahead of their task. No backend or third-party runtime requests. Static placeholders have no asynchronous loading state.
- Existing planning docs are excluded from the formatting gate to avoid unrelated rewrites. New application/configuration files are formatting-checked in CI.
- No existing graphify graph was present; used direct, task-scoped source inspection without creating graph artifacts. Kept design work within T01's minimal shell scope.
